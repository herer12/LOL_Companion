# Mitarbeit

## Arbeitsablauf

1. Aktualisiere `main` mit `git pull`.
2. Erstelle für jede Änderung einen Branch, zum Beispiel `feat/player-search` oder `fix/profile-loading`.
3. Halte Änderungen und Commits klein und thematisch zusammenhängend.
4. Öffne einen Pull Request nach `main`, beschreibe die Änderung und verknüpfe bei Bedarf ein Issue.
5. Warte auf Review und auf erfolgreiche Prüfungen, bevor du mergst.

## Commits

Schreibe kurze Commit-Nachrichten im Format `typ: beschreibung`, zum Beispiel:

- `feat: add player search`
- `fix: handle missing profile`
- `docs: explain local setup`

Geeignete Typen sind `feat`, `fix`, `docs`, `refactor`, `chore` und `test`.

## Pull Requests

Bitte beschreibe Zweck, wichtige Änderungen und wie du sie geprüft hast. Bei sichtbaren Änderungen füge nach Möglichkeit einen Screenshot hinzu. Geheimnisse, API-Schlüssel und persönliche Konfigurationsdateien dürfen nicht eingecheckt werden.
