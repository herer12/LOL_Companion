# LOL Companion

Ein Companion-Projekt für League of Legends. Funktionsumfang und technische Umsetzung werden gemeinsam festgelegt.

## Mitarbeit

Bitte vor Änderungen die Hinweise in [CONTRIBUTING.md](CONTRIBUTING.md) lesen. Änderungen an `main` erfolgen über Pull Requests.

## Projektstatus

Das Repository befindet sich im Aufbau. Installations- und Startanweisungen ergänzen wir, sobald der Tech-Stack feststeht.

## Konfiguration und Zugangsdaten

Zugangsdaten und lokale Konfiguration gehören nicht ins Repository. Nutzt später eine lokale `.env`-Datei und dokumentiert benötigte Variablen in einer `.env.example` ohne echte Werte.
